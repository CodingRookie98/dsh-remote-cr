### 批次 2 的三条实测数字（供后续引用，别再复述成定值）
- `REBIND=0.0.0.0` 的失败形态**不是单一类**：13 个宿主非回环 IPv4 里 **11 个 `curl: (7)`（连接被拒）+ 2 个 `curl: (28)`（连接超时，172.26.192.1 与 192.168.1.10）**，连同 2 个默认网关共 15 个目标全不可达。把两类折叠成「统一超时」是把观测讲得比实际更整齐。
- ③ 边际带宽观测区间 **30–47 MiB/s**（多轮样本 30–44，上界留一档余量）；③ 固定开销 `a₃` **5–25 ms/请求**；折损 **≤1.7×**。这三个是区间不是定值——单轮样本给出的 6.26×/1.18× 已被 `delta-r1` 复跑推翻过。
- A11 的可假性靠**退化护栏**保证：载荷 0/0 B 时阈值不参与判定（`probe.cjs:440-442` 的 `bridgeCarried`），否则 `fit()` 在 `b=0` 时返回 `thr=Infinity`，会把「没有数据」读成「没有成本」。负控实跑证实护栏生效（打印「不可用」而非荒谬值）。
