## 4. 我不确定的地方（审查优先打这里）

1. **多实例**：directoryFlow 的两个洞（侧栏 + 会话空态）同时打开时，restoreFocusAfterNav 与 wakeController 是模块级单例。R2 签了「体验问题可接受」，但**没人真的开过两个**。
2. **冷启动窗口**：wsl/timeout 的 60s 是按一次真机观测（>20s 未起完）定的；热启动分布没测。
3. **WSL 失败卡的真机证据不完整**：当天真机抓到的是**超时**；vhdx 挂载失败（E_INVALIDARG）那次是 shell 层复现 + 预览场景 + 单测，**没有真机截图**。现在这台机器的 ubuntu_dev 起得来，要复现得先弄坏 vhdx。
4. **SSH 不在向导里**：点 SSH 只给一句「请用右侧面板」（R2-D5），接入仍走面板。这是产品口径还是缺陷，需要人判。
5. **lib/ 仍是入库产物**：分层约定已写（AGENTS.md §4），但历史提交里仍有 10 个带 lib/ —— 仓库规则禁止 rebase，没重写历史。
6. **未验证域**：真实宿主 slot 容器里的像素与性能（预览 harness 不是宿主容器）、Edge/Firefox/WebKit、屏幕阅读器读屏路径、窄视口触屏。
