# 敏感信息规则（开源前必读）

> 本仓库要公开。任何**真实环境标识**都不得进入可被 git 追踪的文件。

## 1. 禁止写入

| 类别 | 例子（不要写） | 占位符 |
|---|---|---|
| 真实主机/IP（含私网、ZeroTier） | 任何真实网段（不举例，写了就是泄露） | `203.0.113.x` / `198.51.100.x` |
| SSH 别名 / 用户名 | 具体别名、`dev` 等 | `<target-host>` / `dev` |
| 私钥路径与文件名 | `.../.ssh/<自定名>` | `id_ed25519` |
| 防火墙规则 GUID、`netsh` 具体规则名 | `{30d0c46c-…}` | `<rule-guid>` |
| 内网拓扑（别名组、服务主机名） | 某机器同时叫 A/B/C | 只说「共享宿主机」 |

## 2. 允许写

- 环回与文档保留地址：`127.0.0.1`、`0.0.0.0`、`203.0.113.0/24`、`198.51.100.0/24`。
- 通用端口（8899/8941…8961 这类约定端口可以写，它们不指向特定主机）。
- 环境相关的**操作记录**只留在本地，不提交（例如某台 Windows 上 WSL 的搭建步骤，用占位符写成通用模板才可以进 `docs/`）。

## 3. 检查命令

```bash
git grep -I -E '10\.19\.121|192\.168\.5|34\.92\.25|ssy_|id_ed25519' -- . 
```

空输出 = 工作树干净。
